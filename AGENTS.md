# A Plus ICT web project rules

- Use Node.js 22 or newer and make web changes on the `dev` branch.
- Keep the React + Vite architecture; public learning supports Grades 6–13.
- Sinhala Medium and English Medium are separate learning paths.
- Do not invent catalogue data, learner results, prices, ratings, or marketing claims.
- APIs control entitlements and protected content; never weaken that in the frontend.
- Development and staging must be `noindex`; production indexing is controlled by environment configuration.
- Run lint, tests, and a build before completing web changes.
